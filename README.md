# 🐶🐱 Caça-Palavras Animal - Jogo Educativo

Caça-Palavras Animal é um jogo interativo e educativo desenvolvido em React (Vite) com o propósito de conscientizar e informar a população sobre a diversidade de raças de cães e gatos atendidos pela Secretaria Municipal de Direito dos Animais, de forma leve, divertida e dinâmica.

O jogo foi criado especialmente para a FLIS – Feira Literária Itinerante de Saquarema, a pedido da Secretaria Municipal de Direito dos Animais, como parte das ações de educação, conscientização e promoção do bem-estar animal no município.

# 🎮 Sobre o Jogo

O jogador precisa encontrar nomes de raças de cães e gatos escondidos em um caça-palavras antes que o tempo acabe! 

O jogo apresenta:

- Raças de cães e gatos atendidos pela secretaria;
- Desafio contra o tempo para localizar todas as palavras;
- Experiência envolvente e educativa sobre a diversidade animal;
- Conscientização sobre a importância da adoção responsável e cuidados com pets.

Cada palavra encontrada soma pontos, e o jogador pode competir por uma posição no ranking dos melhores participantes!

## [👉 JOGAR AGORA](https://smda-cacapalavras.netlify.app/)

# ✨ Funcionalidades

- 🐾 Caça-palavras dinâmico com nomes de raças de cães e gatos;
- 👤 Configuração do jogador (nome e preferências);
- 🔀 Palavras aleatórias a cada partida para maior desafio;
- ⏱️ Tempo limite para encontrar todas as raças;
- 🏆 Sistema de pontuação e ranking com os melhores jogadores;
- 💾 Armazenamento local das informações e pontuações (via localStorage).

# 🧠 Objetivo Educacional

O Caça-Palavras Animal tem como principal objetivo educar e conscientizar sobre:

- A diversidade de raças de cães e gatos existentes;
- A importância da adoção responsável e cuidados adequados com animais de estimação;
- Os serviços oferecidos pela Secretaria Municipal de Direito dos Animais;
- O respeito e proteção aos direitos dos animais;
- A promoção do bem-estar animal e combate aos maus-tratos.

# 🛠️ Tecnologias Utilizadas

- JavaScript (ES6+)
- React + Vite – Framework moderno e performático
- Styled Components – Estilização responsiva e dinâmica
- Netlify – Hospedagem e deploy
- LocalStorage – Persistência dos dados e ranking local

# 🚀 Como Executar o Projeto

```bash
1. Clone o repositório

$ git clone https://github.com/sistemainternosmecict/jogo-caca-palavras-smda

2. Instale as dependências

$ npm install

3. Rode em modo 

$ npm run dev

4. Gerar versão de produção

$ npm run build
```
